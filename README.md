# Maflow 3D: archivos del agente de contenidos

Este repositorio guarda los archivos que usa y genera el agente semanal de Maflow 3D.
Repositorio **privado**: material de marca y de trabajo. Los archivos que Metricool tiene que
descargar pasan unos minutos por el repositorio público `maflow3d-publicaciones` y se borran.

| Carpeta | Qué va | Quién lo sube |
|---|---|---|
| `marca/` | Logos originales en PNG con fondo transparente (versión para fondo oscuro y para fondo claro) y la fuente Oswald (`.ttf`) | Vosotros, una vez |
| `fotos/` | Fotos reales de piezas, utillajes y la máquina MJF | Vosotros, cuando haya nuevas |
| `docs/` | Ficha de la línea 3D, casos de éxito, eventos | Vosotros |
| `referencias/` | Capturas de publicaciones que os gusten + `notas.md` | Vosotros |
| `packs/AAAA-Sss/` | Reels, imágenes y subtítulos de cada semana | El agente (no tocar) |
| `pruebas/` | Archivos de prueba | El agente |

Para subir archivos: entra en la carpeta → **Add file → Upload files** → arrastra → **Commit changes**.
