# docs/

Documentos de la línea 3D que el agente lee cada semana (PDF, Word o Markdown):

- `ficha-linea-3d`: materiales, tamaño máximo de pieza, acabados, certificaciones, sectores,
  clientes que se pueden nombrar y lo que no se debe decir.
- `casos-exito`: un apartado por caso (cliente o sector, permiso para nombrarlo, reto, solución,
  resultado con cifras confirmadas, fotos de `fotos/` que lo ilustran, orden y si ya se publicó).
- Opcional: ferias y eventos con fechas, hashtags propios o a evitar.

El agente también guarda aquí el resumen de cada semana (`resumenes/`).
